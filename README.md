# singbox-warp-docker

中文 / English project template for `sing-box` (HY2 inbound) with Cloudflare WARP outbound.

## 功能 Features

- 使用 `sing-box` 提供 HY2 + VLESS 入站 / HY2 + VLESS inbounds via `sing-box`
- 出站走 Cloudflare WARP（通过 `wgcf` 生成 WireGuard 配置）/ Outbound via Cloudflare WARP (WireGuard profile generated by `wgcf`)
- 配置文件可在构建前手动编辑 / Config files are editable before build
- GitHub Actions 定时重建镜像，实现版本自动刷新 / Scheduled GitHub Actions rebuild for automatic version refresh

## 快速开始 Quick Start

1. 编辑 `config/sing-box.template.json`  
   Edit `config/sing-box.template.json`
- 设置 `hy2` 的监听、用户密码、TLS 证书路径  
  Set `hy2` listen settings, user password, and TLS cert/key paths
- 默认最终出站是 `warp`  
  Default final outbound is `warp`

2. （可选）编辑 `config/wgcf-account.toml`  
   (Optional) Edit `config/wgcf-account.toml`
- 如果你已经有 WARP 账户文件，可直接放入复用  
  If you already have a WARP account file, place it here to reuse
- 如果没有，容器首次启动会自动注册  
  If missing, container auto-registers on first start

3. 端口自动适配（推荐）  
   Auto port adaptation (recommended)
- 复制 `.env.example` 为 `.env`，修改高端口（默认 `HY2_PORT=32443`、`VLESS_PORT=38443`）  
  Copy `.env.example` to `.env` and set high ports (defaults: `HY2_PORT=32443`, `VLESS_PORT=38443`)
- 启动时会自动写入 `config.json`，日志中的节点链接也会同步端口  
  Ports are injected into final `config.json` at startup, and printed node links use the same ports

4. 本地构建并运行  
   Build and run locally

```bash
docker compose up -d --build
```

5. 查看日志  
   Check logs

```bash
docker compose logs -f
```

## 持久化数据 Persistent Data

- `./data` 会挂载到容器内 `/var/lib/wgcf`  
  `./data` is mounted to `/var/lib/wgcf` inside container
- 这里保存 WARP 注册信息和生成的 profile  
  This stores WARP registration data and generated profile
